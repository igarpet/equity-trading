# Residual Reversion — Avellaneda–Lee sector-ETF residuals on 15-minute bars

S05a–S09: every S&P 500 stock against its sector SPDR, OU s-score of the residual; costs measured from SIP quotes (S05b), exit and entry rules (S05c/S05d), passive execution (S06), continuous weights with a no-trade band (S07/S07b), and diagnostics of the s-score (S08/S09).

Study IDs are kept from the original numbering, so this folder starts at `05a`.
